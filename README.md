# AI Super DJ

Локальный навык для улучшения музыки и сборки DJ-сетов. Один входной файл получает обработку и мастеринг; несколько файлов или папка превращаются в сведённый сет. Исходники сохраняются.

По умолчанию используется **DJ Жилин**: общий темп и фаза обеих дорожек в переходе, плавная передача баса и широкое смешивание середины. При совместимых участках навык стремится к **32 тактам**; короткий источник или конфликт партий могут потребовать меньшего окна. Цель самостоятельного звучания трека — **3–4 минуты**, обычно 210 секунд между переходами; время участия в самих переходах учитывается отдельно.

Порядок по умолчанию сохраняет общий подбор по гармонии, темпу и энергии, с более лёгким началом и плотным финалом. Mood и Fuzzy доступны по явному выбору. Переданный порядок и закрепления имеют приоритет.

## Быстрый запуск

На подготовленном рабочем месте:

```text
superdj make "track.mp3" --output "../result"
superdj make "../music-folder" --output "../result"
superdj make "first.flac" "second.flac" --keep-order --output "../result"
```

Все явно переданные файлы входят в задачу. Для папки используется собственная история готовых сетов; `--allow-repeats` разрешает повторение. Запрос вроде «выбери 20 треков» требует сначала сохранить отдельный список выбранных файлов: `make` сам не ограничивает их число.

Другие варианты выбираются явно:

```text
superdj make "../music-folder" --style sync --output "../result-sync"
superdj make "../music-folder" --harmonic-mode mood --output "../result-mood"
superdj make "../music-folder" --harmonic-mode fuzzy --output "../result-fuzzy"
```

`sync` включает обычные F/SYNC-кривые, сохраняя общий темп и фазу. Настройка `default_style` в собственной конфигурации меняет предпочтение пользователя; явный `--style` имеет приоритет. Одиночный файл обрабатывается без пересведения.

## Что входит в результат

Готовый сет — FLAC 24 bit и CUE с фактическими началами треков. На настроенном рабочем месте в папку выдачи попадают только музыка и CUE, а анализ и промежуточные файлы остаются в приватном рабочем каталоге. Имена обычных сетов имеют вид `YYYY_MM_DD_FolderName`. Существующий мастер не перезаписывается без явного запроса.

Обработка проверяет источники, границы фраз, совпадение ударных в готовом переходе, поддержку баса и возможный конфликт голосов. Непроверенная сетка не считается подтверждённым сведением. Финальный FLAC проверяется после кодирования: длительность, формат, громкость и пики. Перевод MP3 в FLAC не восстанавливает уже потерянные детали.

## Установка

Нужны Python 3.12, FFmpeg/FFprobe, Rubber Band CLI и подготовленные локальные модели для нейросетевых функций. Установка одних инструкций навыка не устанавливает аудиодвижок и веса моделей.

```text
python -m pip install -e ".[test,repair]"
superdj setup --components ../superdj-work/checkouts
```

Для агента установите `ai-super-dj` из корня [репозитория](https://github.com/istepachev/AI-Super-DJ), затем попросите подготовить локальные инструменты по [инструкции установки](references/friend-setup.md). Она содержит готовый запрос для другого компьютера. Файл `assets/runtime-zhilin.example.json` — пример конфигурации, а не автоматически готовые пути.
