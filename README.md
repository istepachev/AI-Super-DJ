# AI Super DJ

Проверка ритма различает найденный похожий удар и доказанную основную долю: сбивки сохраняют исходный рисунок. После каждой коррекции заново измеряется фактическая карта скорости; старый отчёт не может пропустить чрезмерное сжатие соседних фрагментов. При неопределённых атаках ударные передаются последовательно, а длинное смешивание мелодий сохраняется. Проверяется и тихая уходящая сторона наложения. Подробнее — [проверка акустического сведения](references/acoustic-sync.md).

Повторная сборка умеет использовать проверенные этапы по SHA-256, сохранять модели в памяти на время запуска и распределять задачи между настроенными GPU. По умолчанию постоянный кэш выключен; `--cache` включает его в выбранной папке, `--no-cache` отключает для запуска. Временное место для обработки всё равно нужно. [Настройка ускорения и хранения](references/performance.md).

Локальный навык для улучшения музыки и сборки DJ-сетов. Один входной файл получает обработку и мастеринг; несколько файлов или папка превращаются в сведённый сет. Исходники сохраняются.

По умолчанию используется **DJ Жилин**: общий темп и фаза обеих дорожек в переходе, плавная передача баса и широкое смешивание середины. При совместимых участках навык стремится к **32 тактам**; короткий источник или конфликт партий могут потребовать меньшего окна. Цель полной игры трека — **3–4 минуты**, обычно 210 секунд **вместе с входящим и исходящим переходами**. Максимум — 5 минут; он проверяется по фактически подготовленному звуку. Время между отметками CUE и время самостоятельного звучания указываются отдельно.

В режиме DJ Жилин порядок по умолчанию использует Mood вместе с подбором по темпу и энергии, с более лёгким началом и плотным финалом. Другие стили по умолчанию используют Classic. Явный выбор `--harmonic-mode classic`, `mood` или `fuzzy` и настройка `default_harmonic_mode` имеют приоритет. Переданный порядок и закрепления сохраняются. Mood меняет гармонические предпочтения; динамика сета также зависит от самих треков и его энергетического развития.

## Быстрый запуск

На подготовленном рабочем месте:

```text
superdj make "track.mp3" --output "../result"
superdj make "../music-folder" --output "../result"
superdj make "first.flac" "second.flac" --keep-order --output "../result"
```

Все явно переданные файлы входят в задачу. Для папки используется собственная история готовых сетов; `--allow-repeats` разрешает повторение. Запрос вроде «выбери 20 треков» требует сначала сохранить отдельный список выбранных файлов: `make` сам не ограничивает их число.

Навыку можно сказать «собери около часа из этой папки»: агент сначала выбирает состав и оценивает длительность с учётом наложений, затем сообщает фактическую длину результата. У `make` пока нет отдельного ограничения общей длительности. «Замени этот трек» использует существующий процесс исправления. «Сохрани припев с 2:10 до 2:45» задаёт защищённый фрагмент по желанию пользователя; обычная сборка не требует дополнительных вопросов о припевах. DJ Жилин уже выбирает содержательное ядро по структуре и энергии, но не обещает распознавать каждый припев.

Перед обработкой проверяются доступная память и временное место. Неудачный автоматический переход может попробовать другое допустимое окно той же длины. Для исправления готового сета есть `revise`: смена окна сохраняет порядок, а удаление трека заново подбирает оставшуюся последовательность после места удаления. Старый сет сохраняется. [Исправления и ресурсы](references/revisions.md).

Другие варианты выбираются явно:

```text
superdj make "../music-folder" --style sync --output "../result-sync"
superdj make "../music-folder" --harmonic-mode mood --output "../result-mood"
superdj make "../music-folder" --harmonic-mode fuzzy --output "../result-fuzzy"
```

`sync` включает обычные F/SYNC-кривые, сохраняя общий темп и фазу. Настройка `default_style` в собственной конфигурации меняет предпочтение пользователя; явный `--style` имеет приоритет. Одиночный файл обрабатывается без пересведения.

Длинные проигрыши включаются только по явному запросу для конкретной сборки:

```text
superdj make "../music-folder" --long-play --track-play-seconds 360 --output "../result-long"
```

Здесь цель — 6 минут полной игры; допустимый максимум — 7 минут. Без `--long-play` цель ограничена 180–240 секундами и максимум остаётся 300 секунд. Сохранённая настройка рабочего места не включает длинные проигрыши автоматически.

## Чтение аудиоформатов

На подготовленном компьютере исходники всех поддерживаемых форматов читаются одним FFmpeg, включая вход CUE-DETR. Для MP3, FLAC, WAV, AIFF, AAC/ALAC в M4A, Ogg/Opus, WMA и других поддерживаемых контейнеров не нужны отдельные кодеки, audioread или настройка PATH. Путь к уже подготовленному декодеру передаётся нейросетевому процессу явно. Реальный формат определяется по содержимому: файл M4A с именем `.m4a.mp3` тоже читается правильно. [Поддерживаемые форматы и проверки](references/audio-formats.md).

## Что входит в результат

Готовый сет — FLAC 24 bit и CUE с фактическими началами треков. На настроенном рабочем месте в папку выдачи попадают только музыка и CUE, а анализ и промежуточные файлы остаются в приватном рабочем каталоге. Имена обычных сетов имеют вид `YYYY_MM_DD_FolderName`. Существующий мастер не перезаписывается без явного запроса.

Обработка проверяет источники, границы фраз, совпадение ударных в готовом переходе, поддержку баса и возможный конфликт голосов. Основные атаки и пропущенные басовые акценты проверяются раздельно на обеих слышимых дорожках. Совпадение верхнего щелчка не скрывает смещение баса. Если один удар маскирует другой, дополнительная проверка использует известные вклады дорожек в итоговый переход; её результат сохраняется отдельно от проверки общей волны. Неразрешённое смещение или потеря распознанного басового акцента останавливают выдачу. Непроверенная сетка не считается подтверждённым сведением. Финальный FLAC проверяется после кодирования: длительность, формат, громкость и пики. Перевод MP3 в FLAC не восстанавливает уже потерянные детали.

## Установка

Нужны Python 3.12, FFmpeg/FFprobe, Rubber Band CLI и подготовленные локальные модели для нейросетевых функций. Установка одних инструкций навыка не устанавливает аудиодвижок и веса моделей.

```text
python -m pip install -e ".[test,repair]"
superdj setup --components ../superdj-work/checkouts
```

Для агента установите `ai-super-dj` из корня [репозитория](https://github.com/istepachev/AI-Super-DJ), затем попросите подготовить локальные инструменты по [инструкции установки](references/friend-setup.md). Она содержит готовый запрос для другого компьютера. Файл `assets/runtime-zhilin.example.json` — пример конфигурации, а не автоматически готовые пути.
