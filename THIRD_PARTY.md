# Dependency provenance

SuperDJ's original orchestration and skill instructions use the MIT license in [LICENSE](LICENSE). External programs, Python packages, source checkouts, models, and music retain their own licenses. No upstream executable or complete checkout is vendored. The CUE-DETR preprocessing adaptation retains its upstream MIT notice. Adapter availability and actual execution are separate facts; the local run manifest records both.

## Integration policy

- Keep external checkouts and binary downloads outside the public repository. Record their exact revision or package version in private run manifests.
- Prefer stable functions or subprocess interfaces. Any adapter correction must be identified as a local adaptation and tested on generated signals before use with music.
- If upstream source is later copied, preserve its applicable license and notices. In particular, copies or substantial portions of audamcp require its MIT notice. Recheck the actual revision before extending the integration.
- If a release later bundles or links FFmpeg/Rubber Band, review that release's build and distribution obligations and include the required source/license materials. The initial separate-executable design must not be represented as permission to relicense those programs.
- Python dependency licenses are available from the installed distributions. Record the environment used; do not imply that this file replaces their notices.
- The pinned Bitwize adapter can replace only its look-ahead limiter's Python envelope loop with a locally compiled float64 recurrence after validating the exact loop structure. Other upstream operations are retained; fast-math and persistent JIT caching are disabled. This is an identified runtime adaptation, with exact seeded full-master comparisons and an upstream fallback. Numba is an optional installed dependency; no compiler binary is bundled here.
- An additional identified adaptation distributes the pinned `_measure_lra` function's independent windows across bounded CPU threads only after validating the exact function AST. Every window retains the upstream loudness calculation, filter reset and result order; the upstream percentile calculation remains unchanged. Unrecognized code, insufficient resources or worker failure retain the serial calculation. No upstream checkout is modified.

The sequence optimizer is an original, transparent implementation based on stated musical costs. DeckWave's harmonic-transition workflow and music-hearing's acoustic descriptors informed the design review; their code is not copied into this repository.

The ordinary mastering preset also has an identified bounded-memory adaptation in `superdj.stream_master`. It validates the pinned upstream functions, carries the original float64 highpass/limiter state across blocks and retains polyphase context, whole-file gating and dither draw order. The installed pyloudnorm meter is inspected and adapted at runtime only after exact function checks: its gating/reductions remain in place while filtered window energies are streamed. External source checkouts are unchanged. Unsupported code stops bounded processing rather than allocating the full recording. Temporary DOUBLE PCM is removed after use. This adaptation covers the ordinary adapter preset, not arbitrary upstream genre processing.

Music and personal playlists are local inputs. The project's software license grants no rights to publish those recordings. The public code repository excludes them by design.

## Neural cue and voice adapters (0.8)

- [ETH-DISCO/cue-detr](https://github.com/ETH-DISCO/cue-detr), audited revision d0462856ed2f59a1fb65267cfbe87340a65ad1bb, MIT, copyright 2024 ETH DISCO. The local preprocessing/inference adaptation in superdj.cues retains [the complete notice](licenses/CUE-DETR-MIT.txt). Its batching is bounded to 32, unlike the upstream whole-track batch. Fusion with structure/grid evidence is original code.
- [disco-eth/cue-detr weights](https://huggingface.co/disco-eth/cue-detr), model-card license MIT. Audited model.safetensors SHA-256: 195b80f5c94e4b424b417a7c04e0aac238082c584ddcb65d01be8a97c69cadd3. Configuration/processor hashes are checked in superdj.cues. No weights are bundled; the Facebook DETR image processor is an external transformers dependency.
- [Demucs](https://github.com/facebookresearch/demucs), package 4.0.1, [MIT](https://github.com/facebookresearch/demucs/blob/v4.0.1/LICENSE), copyright Meta Platforms, Inc. and affiliates. Optional local vocal estimator via public get_model/apply_model functions. The upstream repository is archived; pinning and a compatible isolated environment are intentional. Official htdemucs checkpoint 955717e8-8726e21a.th had SHA-256 8726e21a993978c7ba086d3872e7608d7d5bfca646ca4aca459ffda844faa8b4 in validation; actual weights/settings are recorded per run. Estimated vocal energy is not a calibrated probability. No upstream source or weights are copied into this repository.
